# AIIMS Patna Sarthi

Hospital navigation + OPD saathi app — mareez ko gate se lekar doctor, janch, report aur agli visit tak raasta dikhaata hai.

**Live app:** https://abhinavpathak4120.github.io/aiims-patna-sarthi/

---

## App (repo root)

| File | Kaam |
|---|---|
| `index.html` | Poori app — ek hi self-contained file (136 screens, 4 bhashaayein) |
| `manifest.json` | PWA manifest (install + naam + icon) |
| `sw.js` | Service worker — ek baar online khulne ke baad offline chalne ke liye |
| `icon-192.png`, `icon-512.png` | App icons |

**Bhashaayein:** Hindi · English · Bhojpuri · Maithili
**Features:** indoor navigation (floor plan, AR camera, QR), OPD token aur live katar, janch aur report, payment, emergency 24x7, appointments, accessibility (bada text, dark mode, voice).

> **Demo note:** ye ek prototype hai — sirf sample data. Asli mareez ki jaankari na daalein.
